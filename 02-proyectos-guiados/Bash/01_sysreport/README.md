# Generador de Ficha de Sistema (CLI Utility)

Una utilidad de línea de comandos robusta escrita en Bash para obtener un reporte instantáneo del estado de un servidor Linux.

## 🚀 Funcionalidades
- Reporte detallado de usuario, hostname, kernel, uptime y fecha.
- Interfaz visual formateada con marcos ASCII.
- Gestión de argumentos para ayuda (`--help`).
- Manejo de errores y códigos de salida estándar POSIX.

## 🛠️ Requisitos
- Sistema operativo compatible con Bash (Linux, macOS, WSL2).
